تفاصيل مشروع التخرج الهندسي (SENTINEL Project)

معمارية المنظومة الهجينة رباعية الأبعاد (Hybrid Architecture)

يقدم مشروع SENTINEL حلاً شاملاً لسد الفجوة بين الكشف البرمجي عن التهديدات والاستجابة المادية اللحظية، متغلبًا على مشكلة "إجهاد التنبيهات الرقمية" (Alert Fatigue)[span_17](start_span)[span_17](end_span). يعتمد النظام على أربع ركائز أساسية:

1. السيرفر المركزي (Flask Backend)

مبني بلغة Python وخادم Flask للتحليل السحابي اللحظي، تتبع معدلات الطلبات (Rate Limiting)، والتفاعل المباشر مع جدار حماية ويندوز (Windows Firewall عبر Netsh) للحظر الآلي الفوري لأي عناوين IP مشبوهة خلال أقل من 100 مللي ثانية[span_18](start_span)[span_18](end_span)[span_19](start_span)[span_19](end_span).

2. العتاد والاستجابة الفيزيائية (Arduino)

ربط رقمي مع لوحة Arduino Uno عبر منفذ Serial، لتوليد إنذارات مادية حسية (صوتية عبر Buzzer بترددات متباينة، وضوئية عبر LEDs، وعرض تفاصيل الهجوم على شاشة LCD)، بالإضافة إلى دمج حساس الحركة PIR لتفعيل النظام فقط عند الوجود البشري حفاظاً على الطاقة[span_20](start_span)[span_20](end_span)[span_21](start_span)[span_21](end_span)[span_22](start_span)[span_22](end_span).

3. لوحة التحكم المتنقلة (Flutter App)

تطبيق موبايل تفاعلي مبني بـ Flutter لإدارة المنظومة عن بعد، يتيح المراقبة الإحصائية للتهديدات (Dashboard عبر الرسوم البيانية)، التحكم اليدوي في الحظر والفك (Firewall Control)، وإدارة صلاحيات المستخدمين (RBAC)، وتوليد تقارير تدقيق رسمية بصيغة PDF[span_23](start_span)[span_23](end_span)[span_24](start_span)[span_24](end_span)[span_25](start_span)[span_25](end_span).

4. الذكاء الجمعي والفحص السحابي

التكامل مع منصة Virustotal API v3 لاستعلام البصمات الرقمية للملفات (SHA-256) وفحص ترويسات ملفات الـ PE دون الحاجة لرفع الملفات بالكامل، مما يضمن كشف برمجيات اليوم الصفر (Zero-Day) بكفاءة عالية[span_26](start_span)[span_26](end_span)[span_27](start_span)[span_27](end_span)[span_28](start_span)[span_28](end_span).
